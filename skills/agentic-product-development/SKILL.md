# Agentic Product Development Skill

**Core Principles (non-negotiable):**
- Anti-slop at every layer (language, visuals, UX, reasoning).
- Impeccable taste + premium asset gates on all outputs.
- Iterative gated loop with evidence.
- Human + AI companion experience testing + real feedback loops.
- Queen-led swarm orchestration + G-Stack specialist roles.
- Interconnected with SIS memory, semantic graphs, assumptions ledger.
- Works for digital products AND SaaS/Gen-as-a-Service.

## Execution Loop (8 phases)

1. **Discover + Reframe** (G-Stack /office-hours style + ICP)
   - Define Ideal Customer Persona per brand.
   - Human + AI companion journey mapping.

2. **Define** 
   - Product packet (facts, inferences, assumptions, unknowns).
   - Thin coherent slice.

3. **Multi-Plan Reviews**
   - Parallel: Product Queen, Eng, Design (taste), DX, Security.

4. **Design + Visuals**
   - Native image gen (xAI + plan Gemini/nano-banana/Codex).
   - Humanizer copy.
   - Premium visuals/infographics.

5. **Build**
   - Multi-CLI (coding-agents: Claude, Codex, Grok).
   - Guardrails.

6. **Test + Companion Experience**
   - Browser QA, split tests, real human+AI simulations.
   - Collect feedback, refine.

7. **Ship / Verify**
   - Local gates first.
   - Evidence packets.

8. **Learn / Retro / Scale**
   - Update assumptions, roadmap, SIS memory.
   - Next bet.
