# 05 — 90-day build and sales plan

## Principle

**Sell a paid pilot before building a platform.** The first goal is not subscription MRR; it is a repeatable paid outcome with admissible proof.

## Days 1–14: choose and prove the wedge

| Owner | Action | Receipt |
|---|---|---|
| Product / Frank | Pick one priority wedge from `02-VERTICAL-WEDGES.md` | completed VERTICAL-WEDGE |
| Research swarm | Interview 10 target operators; collect workflow artifacts with consent | interview synthesis, 10 sources/notes |
| CEO + design + eng | Run App Factory phases 1–3 | product brief, persona, GStack verdict, design contract |
| Sales | Offer 3–5 paid discovery/pilot conversations | calendar + proposal outcomes |
| Ops | Create one landing page with `pilot` truth state | deployed URL + funnel event IDs |

**Gate:** proceed only with a named painful job and at least one paid pilot or a documented adjustment after qualified objections.

## Days 15–45: pilot and evidence

| Owner | Action | Receipt |
|---|---|---|
| Delivery swarm | Configure one core workflow for pilot customer | scope + acceptance criteria |
| Product | Implement only primary job | deployed preview + primary-path test |
| Design | Screenshot pack / persona test | evidence folder + scorecard |
| Client owner | Approve outputs/side effects | approval receipts |
| Ops | Meter time/cost and capture objections | unit-economics log |

**Gate:** the pilot produces a measurable output, customer says why it matters in their language, and at least 70% of work is reusable.

## Days 46–75: extract the product

1. Remove client-specific details from shared core.
2. Convert repeated steps into config/schema/skills, not forked code.
3. Build the first Outcome Kit package.
4. Publish one evidence-backed case study (with approval) and one educational proof artifact.
5. Create onboarding, license, support/update policy and refund/eligibility terms with professional review where needed.
6. Create a second pilot/first kit buyer path.

**Gate:** a non-builder can achieve first success from docs/demo in ≤60 minutes—or the kit is not ready.

## Days 76–90: monetize and repeat

| Build | Decision |
|---|---|
| Checkout + delivery | only for a ready, tested kit |
| Guided install offer | launch with fixed scope and calendar |
| Subscription/AaaS | launch only if recurring outcome and support economics exist |
| Partner deck | only after 2+ evidence-backed outcomes |
| Vertical backlog | promote only common patterns observed in pilots |

## Weekly cadence

- **Monday:** pipeline review; one bottleneck and one offer decision.
- **Tuesday–Thursday:** customer interviews/pilots and build.
- **Friday:** evidence review, pricing/retention review, publish only verified proof.
- **Monthly:** kill/pivot/proceed using `07-MEASUREMENTS-AND-DECISION-LOG.md`.

## First 30-minute action

Create a product brief for the **Creator Product Engine** or **AI-Native Expert Practice**. Do not choose a third option until that brief receives a GStack GO/PIVOT/KILL verdict.
