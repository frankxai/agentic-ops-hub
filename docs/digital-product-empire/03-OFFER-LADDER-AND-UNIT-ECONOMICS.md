# 03 — Offer ladder and unit economics

## Canonical ladder

Use one semantic ladder across brands. Price and delivery vary by persona, not the meaning of the stage.

| Stage | Customer gets | Revenue model | Proof required before public sale |
|---|---|---|---|
| Discover | source-backed perspective / useful example | free | real artifact and source/date |
| Diagnose | scorecard, path selector, mini audit | free or low-ticket | correct routing + useful result without purchase |
| Prove | mini kit / implementation lesson | free or low-ticket | a user completes a small job |
| Start | **Outcome Kit** | one-time | bootable asset + docs + license + update policy |
| Install | guided configuration + launch | fixed fee | precise scope + delivery playbook + handoff |
| Scale | recurring vertical SaaS / AaaS | subscription + usage | reliable product + metering + support + retention loop |
| Compound | partner license / training / rev-share | annual, cohort, or negotiated | multiple evidence-backed customer outcomes |

## Initial price logic (hypotheses, not market facts)

Set price from avoided work, repeatability and support cost—not model tokens.

| Offer | Indicative position | Fulfilment boundary |
|---|---:|---|
| Diagnostic / scorecard | free–€49 | automated or short reviewed output |
| Focused Outcome Kit | €79–€299 | self-serve; documentation-first; community/support boundary clear |
| Pro kit / studio starter | €349–€1,250 | includes repo, configuration, implementation rationale, updates defined |
| Guided install | €1,500–€7,500 | one workflow, fixed scope, fixed calendar, named handoff |
| Paid vertical pilot | €5,000–€20,000 | discovery + configured deployment + evidence; no open-ended custom development |
| Recurring AaaS | €300–€3,000+/month + usage | one business outcome, roles, receipts, support/SLA boundary |
| Partner/enterprise system | €15k–€100k+/year | license, onboarding, controls, and verified support commitments |

Prices should be tested through paid pilot conversations; do not publish a range as a permanent list price until checkout/fulfilment/support are ready.

## Outcome Kit standard

A product is not an Outcome Kit until it has all of:

```text
working artifact/repo
+ 30–60-minute first success
+ user/job-specific configuration guide
+ license and allowed use
+ demo data or sandbox
+ verification steps
+ support boundary
+ changelog/update policy
+ next paid step
```

### Candidate first three kits

1. **Creator Product Launch Kit**
   - operator: educator/expert with an existing body of knowledge
   - output: validated offer page + launch asset system + delivery checklist
   - route: GenCreator

2. **AI-Native Practice Intake Kit**
   - operator: specialist advisor/agency
   - output: structured discovery → client brief → human-approved plan → receipts
   - route: FrankX / Starlight Intelligence

3. **Governed Content Operations Kit**
   - operator: small brand/marketing lead
   - output: brief → produce → review → approve → distribute → learn loop
   - route: GenCreator / Starlight Intelligence

## Unit economics gates

| Metric | Kit | Install | Subscription |
|---|---:|---:|---:|
| Gross margin goal | ≥85% | ≥60% | ≥75% (after model + infra) |
| Time to first success | ≤60 min | ≤14 days | ≤1 day onboarding |
| Human support per customer | ≤90 min | contract-capped | declining after onboarding |
| Repeatable code/workflow | ≥80% | ≥70% | ≥90% |
| Retention proof | n/a | upgrade/renewal signal | 90-day active outcome use |

If a service requires new custom architecture every time, sell it as a high-price bespoke engagement—or reject it. Do not call it SaaS.

## Revenue flywheels

```text
Client pilot → evidence + objections → improved kit → content/case study
→ self-serve buyers → qualified installs → recurring AaaS → partner license
→ more domain examples and stronger product moat
```

### What compounds

- owned workflow/IP and versioned templates
- customer-approved anonymized evidence
- installation checklists
- skills and evals
- vertical schemas/connectors
- permissioned benchmark data only where consent and sovereignty permit

### What does not compound

- one-off prompts
- random template bundles
- commodity image packs
- unmetered AI costs
- custom dashboards without a shared model
