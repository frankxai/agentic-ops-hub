# Creative Direction: Agent Workbench OS

Status: rebuilt social candidate direction.

## Creative Thesis

Stop visualizing agentic work as tool stacks. Show it as a founder workbench:
requests enter, agents prepare, sources anchor truth, proof accumulates, and
human approval controls the irreversible moves.

## Visual Idea

The carousel is a black editorial workbench with six physical operating surfaces:

1. Intake tray
2. Active bench
3. Source ledger
4. Proof wall
5. Approval gate
6. Learning shelf

This is more ownable than another grid of AI tools and more reusable than a
Slack-first cockpit diagram.

## Signature Motif

- Cyan/emerald rails: agent work in motion.
- Amber gate: human judgment and approval.
- White proof packets: verified output.
- Obsidian grid: operating discipline.
- Large editorial type: founder-to-founder, not corporate.

## Keep

- Direct FrankX language.
- One idea per slide.
- Visible operating mechanism.
- Deterministic exact text.
- Strong mobile first-read.

## Cut

- Generic "AI will change everything" claims.
- Tool-name soup.
- Fake dashboards.
- Raw generated text.
- Tiny labels required for comprehension.
- Repeated dark cards with no rhythm.

## Slide Rhythm

1. Iconic cover: agents need a workbench.
2. Failure mode: prompts alone create drift.
3. New model: the six-surface workbench.
4. Six surfaces: intake, bench, source, proof, approval, learning.
5. Agents prepare; humans approve.
6. The operating packet.
7. Proof before autonomy.
8. Current official lab signal.
9. Starter setup.
10. CTA and source note.

## Image System

Production method for this run: deterministic editorial graphics. Rationale:
the last generated cover was not campaign-defining, and this topic needs exact
labels, diagrams, and compositional control more than cinematic mood.

Future generated cover exploration is acceptable only if it uses three distinct
directions, inspection, critique, and a result that beats the deterministic cover.

## Platform Behavior

LinkedIn: use the 10-slide PDF and PNG sequence.

Instagram: use the same 4:5 art direction but shorten captions and avoid dense
source footnotes on individual slides. This pack includes the PNG/JPG sequence;
Instagram copy should be cut before external use.
