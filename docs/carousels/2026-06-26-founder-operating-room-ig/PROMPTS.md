# Image Generation Prompts

Mode: built-in `image_gen`

All prompts followed the same production constraints:

- 4:5 portrait source frame for Instagram carousel.
- Premium editorial founder/business art direction.
- Brand tokens: #05060A, #0A0C14, #F1F3F9, #6EA8FE, restrained warm gold.
- No readable text, no logos, no watermarks, no fake UI labels.
- Exact typography and channel names are rendered later in code, not trusted to image generation.

## Source 01

Concept: Founder Operating Room.

Prompt direction: elegant dark founder command studio with printed system maps, repo cards, website/domain health boards, social content storyboards, camera prep notes, approval paths, and a thoughtful founder-operator. Cinematic editorial photography, luxury product-design agency art direction, tactile artifacts, strong negative space for typography.

## Source 02

Concept: Slack as cockpit.

Prompt direction: refined command-room wall with layered channel cards, approval queues, daily digest panels, work queue lanes, execution-room lanes, and a human hand placing a card. Premium operations board, physical-digital workflow, no fake Slack logo or readable labels.

## Source 03

Prompt direction: dark trust architecture wall with evidence artifacts: domain health pulses, GitHub branch cards, Vercel preview checks, tests, citations, visual QA stamps, approval paths, and daily report cards as non-readable graphic elements. Founder calmly reviewing the wall.

## Source 04
