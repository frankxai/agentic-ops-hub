# Design System: Agentic Coding OS Carousel

Surface: LinkedIn document carousel, Instagram carousel variant.

Primary format: 1080x1350 slides.

## Brand

FrankX: practical, founder-facing, direct, commercially literate, useful.

AI-Architect: credible, systems-oriented, enterprise-aware, governance-literate.

## Tokens

- Background: `#05060A`
- Surface: `#0A0C14`
- Border: `#1A1F2E`
- Ink: `#F1F3F9`
- Muted: `#8A90A8`
- Accent: `#6EA8FE`
- Secondary accent: `#A78BFA`
- Approval accent: `#F6C86B`
- Proof accent: `#72E6AC`

## Typography

- Primary: Instrument Sans or Geist.
- Fallback: system UI stack.
- Headline: 62-76px, weight 650-750.
- Body: 34-42px.
- Meta: 22-26px.

## Layout Rules

- One idea per slide.
- High contrast, no tiny text.
- Large top-left headline or centered statement.
- Repeated bottom rail: brand, slide number, proof/approval motif.
- Use diagram blocks only when they teach the mechanism.
- Avoid generated fake UI text in final slides.

## Visual Motif

Operating team, not magic assistant:

- lanes
- gates
- proof
- routing
- ownership
- evidence
- approvals
- operating spaces
- source truth
- learning loop

Slack may appear as one cockpit implementation, but the core visual language
should transfer to AI app spaces, projects, threads, branches, and approval
queues.

## Export

Use deterministic HTML/CSS printed to PDF. Use PNG screenshot previews only for
visual review.
