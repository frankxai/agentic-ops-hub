# Taste Direction: Agentic Coding OS Carousel

## Keep

- founder-to-founder directness
- operational specificity
- premium dark interface language
- crisp diagrammatic structure
- useful language that can become a template

## Avoid

- vague "AI will change everything" claims
- generic purple gradient SaaS look
- fake logos
- overpacked diagrams
- tiny labels
- pretending full autonomy is active before proof

## Signature

Agents do not replace management. Agents require a better management system.

## Red-Team Notes

- The deck must not overclaim that Hermes gateways are live.
- The deck should explain the mechanism, not sell vague transformation.
- The strongest educational value is the operating model:
  brief -> branch -> verify -> proof -> approve.
- For Instagram, reduce slide text by 30-40 percent before publishing.
- Do not make Slack the thesis. Slack is one excellent cockpit; the reusable
  thesis is intake -> workspace -> truth -> proof -> approval -> learning.
