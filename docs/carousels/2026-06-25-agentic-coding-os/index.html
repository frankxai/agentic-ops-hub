The Model

Give each layer a job.

Operating spacesChannels, projects, app spaces, and threads for routing.
Source truthRepos, docs, design files, checks, and decision records.
CodexSynthesis, repo work, reports, and approval packets.
Specialist toolsClaude Code, ChatGPT, browser sessions, and focused build tools.
Runtime laterHermes identity and dispatch only after gates are proven.
HumanApproves public, financial, production, and customer-facing action.
Operating stack04 / 10
The Workflow

Use a repeatable execution loop.

1

Brief the agent with outcome, source truth, constraints, and proof required.

2

Work in a branch, thread, project, or bounded app workspace.

3

Run checks and inspect the actual artifact.

4

Return proof with links, decision needed, and learning captured.

Intake -> workspace -> verify -> proof05 / 10
Guardrails

Agents can prepare. Humans approve irreversible moves.

Allowed by default

Research, draft, inspect, test, summarize, prepare branches, produce reports, create approval packets.

Approval required

Publish, merge, deploy, spend, change access, message customers, transfer domains, schedule social posts.

The Prompt

Give agents the operating packet, not a vibe.

A

Objective: what should exist when done?

B

Context: repo, app space, docs, brand, sources.

C

Boundaries: what must not happen?

D

Proof: what link, test, file, or screenshot closes the loop?
