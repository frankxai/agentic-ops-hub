# Creative Direction: Agentic Coding OS Rebuild

Status: rebuild direction, not final approved creative.

Verdict on current pack: `REBUILD_REQUIRED`.

## Creative Thesis

Stop showing "AI agents" as abstract tool cards. Show the operating discipline
that makes agents trustworthy: a founder's command bench where work enters,
proof accumulates, and public action waits behind a human gate.

## First Frame

Headline direction:

```text
Your AI agents do not need more prompts.
They need a workbench.
```

Alternate:

```text
Before agents get autonomy,
give them a place to work.
```

First-frame requirement:

- must feel like a campaign cover, not a slide title
- no dense diagram on slide 1
- one strong object: workbench, proof packet, approval gate, or command ledger
- deterministic title overlay, never generated text

## Visual Thesis

Build the carousel around a proprietary "Agent Workbench" metaphor:

- intake tray
- active work surface
- source ledger
- proof wall
- approval gate
- learning shelf

This is more ownable than generic "AI operating system" cards and more social
than a Slack/GitHub/tool stack diagram.

## Signature Motif

Use a single visual grammar:

- rails for work movement
- stamped proof packets for verification
- amber gate for human approval
- cyan/emerald signal for active agent work
- black editorial surface for FrankX restraint

Do not use floating dashboards, fake UI, or generic glowing rooms.

## Slide Rhythm

The rebuild should use 8 slides for Instagram and 10 for LinkedIn.

LinkedIn:

1. Iconic cover: "agents need a workbench"
2. Failure mode: prompt chaos
3. New model: workbench layers
4. The six operating surfaces
5. What agents can do
6. What humans still approve
7. The operating packet
8. Current lab signal, source-backed
9. Starter setup
10. Save/source note

Instagram:

1. Cover
2. Prompt chaos
3. Workbench model
4. Agents prepare / humans approve
5. Starter packet
6. Save this

## Image System

Generated imagery is allowed only for:

- cover background
- mood frame
- thumbnail

Required process:

- generate at least three distinct cover directions
- inspect all
- reject generic dark rooms, fake text, fake dashboards, and decorative sci-fi
- keep only one if it looks campaign-defining
- otherwise use deterministic editorial graphics instead

Preferred generated-cover concepts:

1. Macro proof packet on black workbench with cyan/amber work rails.
2. Editorial top-down agent workbench with distinct trays and no readable text.
3. Abstract high-end mechanical approval gate with paper proof packets moving
   through it.

Avoid:

- wall of fake notes
- empty dark room
- AI command center cliche
- robot/assistant imagery
- stock office scene

## Typography

Use FrankX directness:

- headline: large, blunt, high contrast
- supporting text: short and useful
- no tiny mono labels required for comprehension
- slide labels may exist but cannot carry the point

## Platform Fit

LinkedIn can teach the operating model.

Instagram must feel more visual and less explanatory:

- fewer slides
- less text
- stronger object focus
- bigger headlines
- less source detail

## Rebuild Acceptance Gate

Do not route to `#social-approvals` until:

- social-confidence score is 90/100+
- generated or deterministic cover is campaign-worthy
- no slide has export/crop defects
- full PNG sequence and contact sheet exist
- design review says "would post this"
- source editor signs off on claim labels
