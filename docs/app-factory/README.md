## Non-negotiables

1. **Job first** — one primary user job before features.  
2. **Think before code** — brief → persona stress → gstack-style CEO/eng/design reviews → then build.  
3. **Brand register** — FrankX ≠ Arcanea ≠ SIS ≠ Vibeclubs.  
4. **Code for exact UI** — Imagine/Grok for atmosphere/heroes; shadcn for product chrome.  
5. **Evidence** — screenshots, a11y, receipts; no “looks premium” without rendered proof.  
6. **Bounded agents** — store-safe permissions; AaaS tools allowlisted.
