## Recording Brief 1: The Guarded 24/7 Agent OS

Brand: Starlight / FrankX

Audience: founders, operators, creators, and technical leaders who want agents
working daily without unsafe autonomy.

Hook: "The mistake is not using agents. The mistake is letting agents act
without proof, ownership, and approval gates."

Three beats:

1. Slack is the cockpit: `#daily-report`, `#work-queue`, `#execution-room`,
   `#repo-command`, `#social-approvals`.
2. Codex is the daily synthesis loop: reports, repo risk, domain watch,
   content prep, and workflow proof.
3. Hermes is the live runtime later: profiles and gateways stay off until the
   Slack proof loop is working.

CTA: "Comment `agent OS` if you want the founder setup template."

- `starlight-portfolio-os-cover-2026-06-25.png`
- `starlight-slack-operating-flow.svg`

24/7 live autonomy until Hermes gateways are actually running.

Approval gate: `#social-approvals`.

## Recording Brief 3: Domain And Deployment Radar

Brand: Starlight / Tooling / AI CoE

Audience: founders with many sites, domains, previews, repos, and launches.

Hook: "If you own many domains and apps, you need a daily radar, not a memory

## Draft Social Copy

### LinkedIn Draft

Most founders do not need more AI tools.

They need an operating system that tells every tool where it belongs.

The setup I am building now:

- Slack as the cockpit
- GitHub as code truth
- Codex as the daily synthesis and repo/domain scanner
- Hermes as the gated live runtime
- Human approval before public actions
- Brand rooms for each business unit
- Social approval before publishing

The important part is the gate:

Agents can research, draft, inspect, test, and prepare proof.

They cannot publish, merge, deploy, spend, or message customers without approval.

That is the difference between "AI chaos" and an agentic operating company.

It is a portfolio OS:

- Slack = cockpit
- GitHub = code truth
- Codex = daily synthesis
- Hermes = gated runtime
- brand rooms = ownership
- approval queues = safety
- proof links = reality

Agents act. Humans approve the irreversible moves.
