## How to use the briefs

Attach the shared execution contract and one specialist brief. The lead fills the assignment fields from verified current records. A placeholder is not a valid write lane. A worker needs exact files and scope before writing. Independent reviewers receive read-only access to the exact final artifact/revision.

```text
Assignment
Customer job: <one concrete valuable task>
Existing product/issue: <verified IDs and links>
Repository/origin: <verified root and remote>
Source/base revision: <immutable revision>
Owned branch/worktree: <free admitted write lane>
Owned files: <explicit paths; no glob covering other workers>
Relevant accepted decisions: <IDs and current source SHA>
Input artifacts: <permitted IDs, revisions and representative examples>
Cash/time/machine limits: <actual admitted limits>
Permitted actions: <existing grants; external effects named separately>
Acceptance: <useful artifact/behavior, baseline and recovery proof>
Handoff recipient: <actual owner or user>
```
