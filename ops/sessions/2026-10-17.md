## Credential isolation and recovery

Eight focused Node tests pass, with staged secret checks enabled. The final
source received an [exact-head independent Claude provider review](https://github.com/frankxai/starlight-agent-config/pull/126#issuecomment-6228263161)
with verdict WARN and no blocking findings; cloud read-back remains unverified.
Earlier review concerns led to actual credential-boundary changes:

- Codex's native shell policy blanks the OTLP authentication variable in tool
  subprocesses. Native config read-back preserves existing user policy entries;
  one real model-invoked shell command confirmed the credential was absent.
- Hermes receives only its harness-prefixed Langfuse keys. Its installed SDK
  authenticated with those keys, and its actual subprocess sanitizer removed
  them. Generic Langfuse keys and the OTLP authentication header are no longer
  supplied to Hermes.
- Child environments remove stale Langfuse/OTLP credentials case-insensitively,
  including on failure. The launcher selects OTLP explicitly and clears inherited
  sampling overrides. A missing Infisical executable now disables tracing and
  allows the harness to start. Invalid setup or unapproved hosts fail closed.

Runtime projection is narrow and backed by private before/after hashes and
backups. Persistent operator credentials were preserved. These controls cover
the verified subprocess boundaries, not arbitrary code running as the same OS
user. Trusted hook/notification inheritance and existing Infisical authentication
variables remain outside that narrower credential scrubber. Signal-terminated
children currently map to exit 1; normal child statuses are preserved.

OpenCode still captures normal assistant-output attributes. Its retry counts are
metrics and are absent from Langfuse with metric instruments disabled. Native
usage/cost mapping and nesting still require actual cloud observations before
claiming complete accounting. Already-running Codex Desktop and Hermes
GUI/gateway processes are outside these CLI launch integrations.
