## Multi-brand docs platform built and shipped as draft PR #1 (OpenCode)

Frank asked for one multi-tenant docs platform for the estate's five brands (frankx, gencreator,
akamoto, arcanea, starlight) instead of the scattered per-agent plans. OpenCode (GLM) built it on
Next.js 16.4.2 + React 19 + Tailwind 4 + Fumadocs v16 in a new canonical repo,
[frankxai/docs-platform](https://github.com/frankxai/docs-platform). One deployment serves every
brand's docs on its own `docs.<brand>` host via host-routed middleware, content lives in-repo as
`content/<brand>/*.mdx`, and every page is agent-native: any docs URL answers either the `.md`
suffix or `Accept: text/markdown` (with `Vary: Accept`) by rewriting onto
`/llms.mdx/<brand>/<path>/content.md`, so an agent reads the docs without a browser. Mobile §11.3
predicates (viewportFit cover, per-scheme themeColor, app manifest, real icon, tap baselines,
hover-gated lift, min-h-dvh) shipped in the same commit.

Verification was local and complete: `npm run build` compiles clean (TS check included) and a
14-point curl sweep is green — negotiation on both triggers, all five brand pages, five
`/llms-full.mdx/*` + `/llms-index/*` feeds, estate and brand `/llms.txt`, OG images, search API,
sitemap, robots, atlas, manifest and icon all return 200. Commit `5c83bc2` (44 files, 8,180
insertions) passed the ops-guard gate and gitleaks, pushed to
`agent/opencode/docs-platform`, and is open as [draft PR #1](https://github.com/frankxai/docs-platform/pull/1).

Incidents from the session, both recorded as lessons: (1) the ops-guard requires an existing HEAD,
so a fresh repo has no way through it — resolved by making one bootstrap `.gitattributes` commit
through the GitHub Contents API and birthing the local branch from it; (2) a `git reset --hard`
during that bootstrap deleted all 42 staged-but-uncommitted files, and full recovery came from the
dangling top-level tree object plus the dangling `AGENTS.md` blob (`git fsck`, byte-identical by
blob SHA) — staged is not untracked, and `gc.auto=0` stays until clean-up is safe.

required before it goes ready), repo visibility, Vercel project creation, and `docs.*` DNS

[the handover](handovers/opencode-docs-platform-20261022.md); details in
