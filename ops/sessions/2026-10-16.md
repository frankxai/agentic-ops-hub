Findings:

  adapter, historical passing test or merged PR does not certify current service.

Proposed responsibility boundaries: Registry owns reviewed portfolio identity and
architecture; SIS owns intelligence/provenance contracts; memory owns scoped
record/retrieval/lifecycle implementation; source owners retain their records;
agent-config owns harness projections; existing Queen/runtime owners govern
admission and durable jobs. A native task lead owns integration, workers own
explicit paths/artifacts, and an independent reviewer judges the exact revision.
Model selection and harness selection are separate from role identity.

Retain the local canonical sources and existing hybrid baseline. Compare Hindsight
and Graphiti for a named advanced-recall job, with Caura as a Postgres challenger.
Choose a document pipeline only for a specific corpus. Personalization remains a
separately scoped experiment. All are proposals pending evaluation.

The alternatives research used current primary sources. Current Graphiti upstream
distinguishes Zep's proprietary Context Graph Engine; Mem0 Platform documents
native graph memory; MemoryGraph currently defaults to FalkorDBLite with SQLite
as a fallback; Hindsight is MIT. The supplied vendor comparisons do not establish
a winner on Starlight's workload.

## Memory economics follow-up

Frank requested RAM, runtime, cost, outcomes, ROI and value comparisons. Current
primary pricing and sizing sources were inspected on 16 October. The source-priced
model and calculations remain in private evidence. No provider was installed,
subscription purchased, auto-topup enabled or heavy benchmark started. Current
resource admission prevents new local heavy work.

Published requirements are separated from observed RSS and topology estimates.
Hindsight documents about 2 GB recommended component allocation for slim API plus
Postgres, or 3 GB for the full API plus Postgres, before system/container overhead
and optional UI/workers. Caura self-host docs specify 4 GB / 2 vCPU minimum.
Neo4j documents a 2 GB development/cloud minimum; Graphiti/API allocations are
additional. Whole-stack RAM for the remaining candidates is unmeasured. Static
observatory RAM entries must not be presented as measurements.

Managed list-price examples: MemoryGraph Pro $5/month; Mem0 Starter $19 and Pro
$249/month; Caura Pro $490/year; Zep Flex $125/month. Cognee lists $1 per million
processed tokens and $5 per additional workspace. Hindsight uses token/call/storage
rates; a clearly hypothetical selective-use example totals $32.50/month in memory
charges. These are not a measured customer bill or a quality-equivalent comparison.

Reuse SIS150's existing cost-per-accepted-outcome and operator-effort gates. Include
inference, context returned to the main agent, maintenance, setup, repair, storage,
backups, deletion and exit effort. Separate fixed subscription headroom from cash
savings and productive recovered time from unproven revenue. Actual ROI and payback
remain unknown until baseline/candidate task evidence and time values exist.
