## Required checks that never reported on frankx.ai-vercel-website (Claude)

Merge Gate and Contract Guard carried a `paths:` filter on a required check, so a pull request that touched only unlisted files (PR 1029, `.nvmrc`) never got a result. Of the eight required contexts only these two had the problem; the other six were confirmed against the workflow files and 1029's rollup. PR 1083 (draft) removes both filters and pins them with a test instead of adding detect logic inside the job, because a detect step would turn "did not run" into "succeeded" for every future file class and the old filter missed only 1 of the last 120 pull requests. Codex reviewed it; the one valid finding (a decoy job name) is fixed. Handover: `required-checks-always-report-20261021`.
