## 1. Fix the deadlocked pipeline  (HIGHEST VALUE — unblocks 4+ PRs)

**Problem:** `agentic-ops-hub` uses *classic* branch protection with
`required_approving_review_count: 1`. Every PR is authored by `frankxai`, the only
collaborator, and GitHub forbids self-approval. The rule is **unsatisfiable** — PRs
#65, #67, #68, #69 can never merge, and clicking "approve" is not possible.

**Note this is an outlier.** `FrankX` and `frankx.ai-vercel-website` already use a
modern *ruleset* with `required_approving_review_count: 0` (require a PR, block
deletion, block force-push, gate on checks). They merge fine. This makes the third
repo match them — it is a normalization, not a weakening.

### Do it yourself (UI, ~30s)
GitHub -> `frankxai/agentic-ops-hub` -> Settings -> Branches -> `main` rule ->
uncheck **Require a pull request before merging** (or set approvals to 0) -> Save.

### Or by API
```bash

gh api -X POST repos/frankxai/agentic-ops-hub/rulesets --input - <<'JSON'

 "conditions":{"ref_name":{"include":["~DEFAULT_BRANCH"],"exclude":[]}},

          {"type":"pull_request","parameters":{
            "required_approving_review_count":0,
            "dismiss_stale_reviews_on_push":false,
            "require_code_owner_review":false,
            "require_last_push_approval":false,
            "required_review_thread_resolution":false,
            "allowed_merge_methods":["merge","squash","rebase"]}}]}
JSON
```

## 3. Stale branches — delete 23, NOT 236

The original audit said "delete 236". **That would have destroyed real work.**
Verified breakdown: 3 fully merged + 20 squash-merged = **23 safe**;
135 have a CLOSED (rejected) PR; **78 have no PR at all and hold 402 commits
that exist nowhere else.**

Exact safe list: `ops/audits/2026-09-15-estate/safe-to-delete-branches.tsv`
Full evidence: `branch-merge-status.tsv`, `branch-verdicts.tsv`

```bash
while IFS=$'\t' read -r repo br; do
  def=$(gh api "repos/frankxai/$repo" --jq .default_branch)
  ahead=$(gh api "repos/frankxai/$repo/compare/$def...$br" --jq .ahead_by)
  pr=$(gh pr list -R "frankxai/$repo" --head "$br" --state all --json state --jq '.[0].state')
  if [ "$ahead" = "0" ] || [ "$pr" = "MERGED" ]; then
    gh api -X DELETE "repos/frankxai/$repo/git/refs/heads/$br" && echo "deleted $repo::$br"
  else
    echo "GUARDED $repo::$br"
  fi
done < ops/audits/2026-09-15-estate/safe-to-delete-branches.tsv
```
The guard re-verifies each branch at delete time; it cannot delete unmerged work.
